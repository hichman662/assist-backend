# MoSIoT TypeActivity → etiqueta humana
1 = medicación
2 = nutrición
3 = mensaje
4 = cita

# Campos frecuentes (guía rápida)
- medication.name: nombre del producto (p. ej., “Ceregumil Original 500 ml”).
- medication.dosage: forma de toma (“cucharada”, “ml”, “tableta”).
- nutritionOrders.name: pauta nutricional (p. ej., “comeNueces”).
- appointments.isVirtual: true = cita virtual; false = presencial.
- comunications[].message: avisos o recordatorios al paciente.
